Bing 每日壁纸归档

收集 Bing 的每日壁纸，让偶然遇见的风景，也能在以后找到。

按分类、颜色或日期慢慢浏览，也可以搜索记得的地点与标题。找到喜欢的照片，就打开看看，或下载留存。

浏览与下载

找到一张照片

底栏的筛选可以组合分类、颜色和日期范围；搜索支持标题、图片说明和日期。

下载一张，或收藏一组

打开照片后可选择分辨率并下载。勾选图片右上角的选择框，即可将多张照片打包为 ZIP。

部分照片没有 UHD 原图，下载时会提示可用分辨率。若浏览器打开了原图，可使用“图片另存为”。

图片从哪里来

壁纸与图片说明来自 Bing，原图链接指向 Bing。每张照片的拍摄者或版权信息可在大图详情中查看。

本站整理和展示这些图片，不拥有图片版权。下载不代表获得其他使用授权，请遵守相应的使用条款。

项目与反馈

归档每日自动更新，分类与颜色由模型辅助标注，可能存在偏差。发现分类错误、下载问题，或需要申请移除图片，可以通过 GitHub Issues 联系维护者。
