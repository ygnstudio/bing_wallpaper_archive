项目简介

Bing 每天都会推送一张高质量壁纸，但官网只保留当天一张、且历史检索极不方便。 本项目用脚本每日抓取并归档原图，沉淀为可检索、可预览、可下载的本地图库。 所有数据均为静态文件，无需后端，可直接部署到 GitHub Pages。

主要功能

多维筛选

按 10 大分类、10 种主色、日期范围快速定位想要的壁纸，并随时搜索标题 / 版权 / 日期。

原图查看

灯箱模式下查看大图，支持 1080p 与 UHD 4K 切换；部分缺 4K 的图会自动回退 1080p。

批量打包

勾选多张后一键打包为 ZIP 下载（纯前端生成，图片不经过服务器），分辨率随所选图可用性自动调整。

智能分类

每日新图经视觉模型（Qwen2-VL）自动打标分类与配色，历史散落误判按需人工修正。

工作原理

抓取脚本每日北京时间 09:00 从 Bing 拉取最新一张壁纸，下载 1080p 原图并本地生成缩略图， 写入 data/metadata.json 并生成前端索引 data/index.json； 分类与配色由视觉模型完成。GitHub Actions 在每次提交后自动重新部署到 GitHub Pages。

4K（UHD）并非每张图都提供，脚本会对每张图探测是否具备 4K 源并标注， 前端据此在下载时限制或自动回退，避免点到无 4K 的图却下不到高分辨率。
